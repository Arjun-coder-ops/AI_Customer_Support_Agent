# Golden Set Labeling Guidelines & Annotation Workflow

> **Status**: BLOCKED — REQUIRES HUMAN INPUT
> **Required**: 150–250 hand-labelled examples before golden evaluation can run.
> **Current count**: See `data/golden/golden_set.jsonl` for current `is_human_reviewed: true` count.

---

## Why Human Labels Matter

The system uses heuristic keyword rules to generate provisional intent labels for training.
The golden set is the ONLY place where a human independently assigns labels, allowing us to
measure whether the classifier generalises beyond the keyword heuristics.

If the golden set labels are also generated by the same heuristics, we cannot claim the
classifier achieves "accuracy" in any meaningful sense — we are only measuring
"does the classifier agree with the rules it was trained on?"

**Human labels break this circular dependency.**

---

## What You Need to Label

File to review: `data/golden/labeling_candidates.jsonl`

Each record has:
```json
{
  "candidate_id": "cand_0001",
  "conversation_id": "conv_XXXXX",
  "customer_message": "<actual Twitter message>",
  "suggested_intent": "<heuristic suggestion — may be WRONG>",
  "human_verified_intent": null,   ← FILL THIS IN
  "is_human_reviewed": false       ← SET TO true WHEN DONE
}
```

**Your job**: For each record, read `customer_message`, decide the correct intent,
and fill in `human_verified_intent`. Add `reviewer` with your name and set `is_human_reviewed: true`.

---

## Complete Annotation Format

When you have labelled an example, the entry in `golden_set.jsonl` should look like:

```json
{
  "id": "cand_0001",
  "conversation_id": "conv_XXXXX",
  "customer_message": "@AmazonHelp my order hasn't arrived and tracking shows no updates for 5 days",
  "suggested_intent": "shipping_delay",
  "human_verified_intent": "shipping_delay",
  "is_human_reviewed": true,
  "reviewer": "YOUR_NAME",
  "review_date": "2026-09-10",
  "escalation_decision": "AUTO_HANDLE",
  "notes": ""
}
```

Fields to fill in:
| Field | Required | Values |
|-------|----------|--------|
| `human_verified_intent` | YES | One of the 8 taxonomy labels below |
| `is_human_reviewed` | YES | `true` |
| `reviewer` | YES | Your name or initials |
| `review_date` | YES | YYYY-MM-DD |
| `escalation_decision` | Optional | `AUTO_HANDLE` or `ESCALATE` |
| `notes` | Optional | Any ambiguities, edge cases, or confidence notes |

---

## Intent Taxonomy (8 Classes)

| Intent Label | Description | Key Indicators |
|---|---|---|
| `shipping_delay` | Order delayed, tracking stuck, late delivery | "where is my order", "tracking shows delayed", "late package", "hasn't arrived" |
| `missing_item` | Received parcel is missing one or more items | "item missing from box", "incomplete shipment", "only received part of order" |
| `order_cancellation` | Request to cancel order before shipment | "cancel my order", "ordered by mistake", "I want to cancel" |
| `refund_return_request` | Return product or get money back | "how to return", "refund status", "return label", "want my money back" |
| `account_access_issue` | Login, password, 2FA, account locked | "cannot login", "reset password", "locked out of account", "2FA not working" |
| `payment_billing_issue` | Double charge, wrong fee, billing error | "charged twice", "billing discrepancy", "payment error", "wrong amount charged" |
| `product_defect_damage` | Received broken, defective, or damaged item | "damaged box", "item broken on arrival", "screen cracked", "defective product" |
| `general_inquiry_feedback` | General questions, compliments, unclear intent | "when will this restock", "store hours", "great service", ambiguous messages |

---

## Edge Case Decision Rules

1. **Damage + refund in same message** → Label `refund_return_request` (the action is refund)
2. **Delayed + cancel in same message** → Label `order_cancellation` (the action is cancel)
3. **Can't determine intent from text** → Label `general_inquiry_feedback`, add note
4. **Message is just "@AmazonHelp hi" or similar** → Label `general_inquiry_feedback`, note as "ultra-short"
5. **Message is in another language** → Label `general_inquiry_feedback`, note "non-English"
6. **Clearly abusive/spam message** → Label `general_inquiry_feedback`, note "off-topic"

---

## Escalation Decision (Optional but Valuable)

If you can also decide whether this message should be escalated to a human agent:

- **AUTO_HANDLE**: Standard query answerable from historical cases
- **ESCALATE**: Legal threat, account mutation, ambiguous, ultra-short, sensitive

## Promoting Labels to Golden Set

After labelling, run:
```bash
python -m src.data.promote_golden
```

This script reads `labeling_candidates.jsonl`, finds all entries where
`is_human_reviewed: true`, and merges them into `golden_set.jsonl`.

Once you have **150+ reviewed examples**, run the full evaluation to unlock
gold benchmark metrics:
```bash
python -m evaluation.run_all
```

---

## How Many to Label?

- **Minimum**: 150 to unlock golden evaluation metrics
- **Target**: 200–250 for meaningful per-class precision/recall estimates
- **Recommended distribution**: ~25 per intent class (8 classes × 25 = 200)

> **Note**: The `labeling_candidates.jsonl` file contains candidates from the
> TEST and VALIDATION splits only — NEVER from training data.
> This ensures the golden set is isolated from training data.
